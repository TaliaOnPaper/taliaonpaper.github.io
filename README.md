# NLS | TOP

Public landing page for **Notch Line Studio** and **TaliaOnPaper**.

Live at: https://taliaonpaper.github.io

## Files

```
index.html     the whole page (HTML, CSS and JS in one file)
logos/         web-sized logos (.webp)
```

## Publishing

1. Create a **public** repo named `taliaonpaper.github.io` on the TaliaOnPaper account.
2. Push this folder to the `main` branch.
3. Settings → Pages → Source: *Deploy from a branch* → `main` / `root`.

Full lore and drafts stay in the private repos. Only teaser blurbs go here.
